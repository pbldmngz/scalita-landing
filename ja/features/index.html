Scalitaでできること

アプリのすべての機能を、何に使うかでグループ分けし、無料かScalita Proかがわかる印を付けました。

  • 無料すべて無料で、期間の制限もありません。
  • 無料 + Pro一部が無料で、一部がProです。どこまでかは説明文に書いてあります。
  • ProScalita Proの機能です。一度の購入でずっと使えます。

ウォームアップ

本物のピアノでのスケールとルーティン。自分の音域に合わせて、キーを1つずつ動かします。

  • スケール

    無料

    メジャーやマイナーからアルペジオ、クロマチック、ロッシーニのパターンまで、23の標準スケールに合わせて歌えます。

  • ルーティン

    無料

    やさしい入門から本格的なトレーニングまで、12の標準ルーティンから選べます。各ステップには、音節、テクニックのヒント、通して意識することが表示されます。

  • スケールプレーヤー

    無料

    1つのスケールを、音域の中でキーを1つずつ進めます。始まりと終わりの位置、テンポ、方向を設定できます。

  • ルーティンプレーヤー

    無料

    ルーティンのステップを順番に、間に息を吸う時間をはさんで再生します。どのステップにも移動できます。

  • 音域

    無料

    最低音と最高音を、歌うか選ぶかして一度設定すれば、どのエクササイズも音域の中に収まります。

  • ウォームアップを探す

    無料

    今日の声の調子と、何に取り組みたいかを答えると、ルーティンとテンポを選びます。

  • アダプティブモード

    無料

    エクササイズがどうだったかを伝えると、次のエクササイズが調整されます。

  • キーの間で息継ぎ

    無料

    新しいキーの前に数秒の無音を入れて、息を吸う時間を作ります。

  • ロック画面の操作

    無料

    ルーティンは画面を消しても再生を続けます。この設定をオンにすると、ロック画面から一時停止やスキップができます。

  • 音名表記

    無料

    音名を、英語音名（C D E）、ドレミ（固定ド）、移動ド、ドイツ音名、ドレミ（Do Re Mi）で表示できます。

学ぶ

最後に実際に歌って終わる短いレッスンと、次に何を練習すればいいかを教えてくれるプラン。

  • ガイド：コース

    無料

    40の短いレッスンを順番に進めます。ほぼすべてのレッスンからエクササイズを開け、どのレッスンにも出典が載っています。

  • ガイド：ライブラリ

    無料

    息やビブラートからディストーションやホイッスルまで、声についての86の項目を調べられます。

  • トレーニングプラン

    無料 + Pro

    7つの用意されたプランから1つ選び、最初から最後まで無料で進められます（一度に1つずつ）。自分でプランを作ることと、一時停止中のプランを2つ以上残すことはProです。

  • プランのリマインダー

    無料

    リマインダーをオンにすると、プランの次のセッションを忘れずにすみます。

  • プランを共有

    無料

    プランをファイルにして友だちや生徒に送れます。人から送られたプランも開けます。

自分の声を見て、聴く

実際に歌ったものを、描いて、採点して、録音します。ピッチの線とスコアにはイヤホンが必要です。

  • ピッチモニター

    無料

    イヤホン（有線またはBluetooth）を着けると、自分の声がどの音に対してもリアルタイムで描かれます。

  • スコア

    無料

    イヤホンを着けると、スケールごとに最後にスコアが出ます。どれだけ音に合っていたか、残りはどれだけ近かったか、そして取り組むべきことを1つ。設定でオンにすれば、ルーティンでもステップごとに採点できます。

  • 自分のテイク

    無料 + Pro

    プレーヤーで「録音」をオンにすると、終わってすぐに聴き返せます。各エクササイズの最新のテイクは誰でも残ります。選んだテイクを保存すること、以前と今を比べること、音声として書き出すことはProです。

  • スペクトログラム

    無料 + Pro

    声の倍音をリアルタイムで、無料で見られます。注目する帯域を決めて30秒を静止表示するのはProです。

  • 録音を開く

    無料 + Pro

    スマートフォンのボイスメモや曲を開いて、無料で聴けます。その音やスペクトログラムを見ること、スケールにすることはProです。

  • 自分の音を知る

    無料 + Pro

    自分の声の場所を見つけてから、曲のフレーズを歌うと、それがどこにあるかがわかります。無料ではフレーズを1つ、最新の記録と一緒に保存できます。Proなら、選んだフレーズをすべて、毎回の記録と一緒に保存できます。

  • シンガーカード

    無料 + Pro

    音域、換声点、練習した日を1枚のカードで見て、共有できます。カードの裏面（音域のどこに音が着地しているか）はProで、その採点にはイヤホンが必要です。

  • 音域を調べる

    無料

    最低音と最高音を歌うと、Scalitaが音域を設定します。画像として共有もできます。

  • 換声点を見つける

    無料

    声の中を音が動いていく間に一緒に歌い、切り替わったところでタップします。Scalitaはその場所を、その周りを練習するエクササイズのために覚えておきます。

  • その他の声区

    無料

    サブハーモニクス、フラジオレット、ホイッスルを使うなら、それぞれの範囲を設定できます。どれにも専用のルーティンがあります。

  • 自分に合わせた練習と、歌の記録

    Pro

    どこで音がずれるか、音域チェックの移り変わり、音程ごとの音感トレーニングを確認でき、合っていることが一番少なかった音をねらったプランのセッションも受けられます。イヤホンを着けて歌ったものを読み取ります。

ツール

イヤホンのいらない2つのツール。

  • チューナー

    無料

    声、口笛、楽器のピッチを確かめ、それがどう動いたかの軌跡を見られます。声、サブハーモニクス、ホイッスル、ギター、ベース、ウクレレ、バイオリン、チェロのプリセットがあります。

  • ドローン

    無料 + Pro

    形を変えられる、鳴り続ける基準の音に合わせて歌います。画面を消しても鳴り続けます。どのドローンも無料で再生でき、1つは保存できます。それ以上保存するのはProです。

音感とゲーム

聴いて、それから歌う。

  • ピッチ合わせ

    無料

    鍵盤をタップして音を聴き、その音に着地します。

  • 聴いて歌う

    無料

    ピアノが短いフレーズを弾き、歌い返すのを待ちます。スマートフォンのスピーカーでも使えます。

  • 音感トレーニング

    無料 + Pro

    音程や短いフレーズを聴いて歌い返し、耳のチェックも受けられます。2つの和音の練習は単体ではProで、レッスンやプランの中では無料です。

  • ハモリ練習

    無料 + Pro

    1つのパートを録音し、その上に次のパートを歌って、4パートまで重ねられます。ハモリを1つ保存するのは無料で、Proなら作った分だけ保存できます。

  • Humming Bird

    無料

    1つの音を伸ばして操る、正確さのゲームです。スマートフォンのスピーカーでも、イヤホンでも遊べます。

自分で作る

タップや歌で作る、自分だけのエクササイズ。

  • スケールエディター

    無料 + Pro

    歌う順番に、休符も含めて鍵盤をタップします。自分のスケールは1つまで無料です。Proなら作ったものをすべて保存でき、標準のスケールも編集できます。

  • ルーティンエディター

    無料 + Pro

    好きな順番にスケールを並べ、ステップごとに音節、テンポ、スタイルを決めます。自分のルーティンは1つまで無料です。Proならすべて保存でき、標準のルーティンも編集できます。

  • スケール検出

    無料

    スケールや短いメロディーを歌うと、Scalitaが聴き取った音を書き出し、自分のスケールとして保存できるようにします。

  • 書き出しと読み込み

    無料

    自分のスケールとルーティンを.scalitaファイルで共有し、人から送られたものを読み込めます。
