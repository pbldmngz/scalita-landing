Note names and octave numbers

One piano key can have several names, depending on where you learned music. Here is how the naming systems and octave numbers line up, so a note on this site means the key you think it means.

Middle C and the octave numbers

Middle C, the C near the middle of the piano, is C4 in scientific pitch notation, the international system this site pairs every note name with. The number goes up by one at each C: the lowest C on an 88-key piano is C1, middle C is the fourth, and the A that orchestras tune to is A4.

Scalita writes Spanish and Turkish solfège with the same count, so middle C is Do4. French and Brazilian solfège count one lower: middle C is Do3 in French and Dó3 in Brazilian Portuguese. German marks the octave with letter case and small numbers instead: middle C is c¹, and the C below it is a plain c.

Why German writes H

In German, the note English calls B is written H, and B means B flat. Sharps add -is and flats add -es, so F sharp is Fis and E flat is Es. A German singer reading an English B would sing a half step lower than meant, which is why Scalita uses German names in German.

Fixed do and movable do

In fixed do, do is always C, re is always D, and so on: the syllables are the note names. Spain, France, Italy, Brazil, Turkey and Latin America name notes this way.

In movable do, do is the first note of whatever key you're in, so a tune sung on do re mi keeps its syllables in any key. Music classes and choirs in English-speaking countries use it, and in Indonesia and China the same idea is written in numbers, 1 for do, under a heading that names the key, such as do = G. Scalita's Numbers notation works this way.

How this site writes notes

Every note name here comes from the Scalita app's own tables: your language's usual system first, with the international name beside it when the two differ. In the app you can switch between Letters, Solfège, German letters and Numbers in the settings.

Common questions

Is middle C C4 or C3?

C4, in the scientific pitch notation most singing material uses. If a keyboard or recording program calls it C3, or C5, it's the same key with another label: the MIDI standard only says that middle C is note number 60.

Which key is middle C on a piano?

On a full 88-key piano it's the fourth C from the left, near the middle. Every C is the white key just left of a pair of black keys.
